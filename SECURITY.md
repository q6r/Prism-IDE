# Relatar uma vulnerabilidade

Para falhas que possam expor arquivos, credenciais, conversas ou acesso remoto, use [o relato privado de vulnerabilidade no GitHub](https://github.com/q6r/Prism-IDE/security/advisories/new). Inclua a versão, o sistema, os passos de reprodução e o impacto observado, usando dados fictícios.

Não abra uma issue pública com tokens, chaves, logins de provedores, bancos de conversas, código privado ou links e QR codes de controle remoto. Um link de controle remoto concede acesso às conversas compartilhadas.

Para problemas comuns de interface ou funcionamento sem exposição de dados, use as issues do repositório. A manutenção é comunitária e não há prazo de resposta garantido.
